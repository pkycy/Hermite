# 这是一个绘制曲线的程序
## 启动指南
1. 将代码拉取到IDEA中
2. 下载21版本的JavaFX SDK(因为17版本后的Java JDK没有内置JavaFX)
3. 参考这篇文章: https://blog.csdn.net/qq_45854695/article/details/139347785 进行相应的配置
4. 启动项目
## 概要
这是一个基于 JavaFX 的图形编辑工具，用于绘制和编辑 Hermite 曲线。用户可以通过鼠标操作添加控制点、调整切线，并生成平滑的 Hermite 曲线。此外，用户还可以将绘制的图像保存为 PNG 文件。
## 主要功能：
1. 添加控制点：用户可以通过鼠标左键点击空白区域添加新的控制点。
2. 调整控制点：用户可以通过鼠标拖动控制点来改变其位置。
3. 调整切线：用户可以通过鼠标右键点击切线的末端并拖动来调整切线的方向和长度。
4. 自动生成切线：如果没有手动设置切线，程序会自动生成切线。
5. 绘制 Hermite 曲线：根据控制点和切线，程序会绘制平滑的 Hermite 曲线。
6. 保存图像：用户可以将绘制的图像保存为 PNG 文件。
